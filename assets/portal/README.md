# Portal fonts

Inter (400/600) and Manrope (600/700) are self-hosted to avoid third-party browser font requests. Retrieved on 29 September 2026 from Google Fonts using:
https://fonts.googleapis.com/css2?family=Inter:wght@400;600&family=Manrope:wght@600;700&display=swap

Unmodified SIL Open Font License texts are included as Inter-OFL.txt and Manrope-OFL.txt, retrieved from the google/fonts repository under ofl/inter and ofl/manrope. See those licenses for redistribution terms. No font tracking or external runtime request is required.
